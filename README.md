# Grisaille

Grisaille is an independent, MIT-licensed Neovim colorscheme project in development.
The current plugin is a foundation for the planned 0.1.0 theme, not the finished
colorscheme. See the [project specification](.scratch/grisaille/spec.md) for the
planned variants and features.
